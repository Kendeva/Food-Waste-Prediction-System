# Dataset

Place the project dataset in this folder using the following filename:

```text
data_penjualan.csv
```

The CSV file should contain these columns:

```text
stok,terjual,hari_ke,cuaca,hari_besar,sisa_persen,label
```

Label values:

- `0` = Safe
- `1` = Potential Waste

The original dataset is not included in this repository package because it was not available in the uploaded project files.
